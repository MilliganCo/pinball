# Fluid+Portal Vox Launcher

> Public source preview: see [PUBLICATION.md](PUBLICATION.md) for actual checks, known failures and runtime limits.

Браузерная игра: запускаем шар в уровнях с воксельной разрушаемостью, жидкостями и порталами. Цель уровня — достичь зоны финиша, используя разрушение и окружение.

## Технологии

- **TypeScript** + **Vite**
- **Three.js r168** + **WebGL2**
- **Vitest** для unit-тестов
- **Playwright** для E2E-тестов
- **ESLint** + **Prettier** для линтинга

## Установка

```bash
# Установка зависимостей
pnpm install

# Разработка
pnpm dev

# Сборка
pnpm build

# Превью сборки
pnpm preview

# Тесты
pnpm test

# E2E тесты
pnpm test:e2e

# Линтинг
pnpm lint
pnpm format
```

## Управление

### Режим прицеливания (AIM)
- **ЛКМ (удержание)** — выбор направления и силы выстрела
- Отпускание ЛКМ — запуск шара

### Режим полёта (FLY)
- Камера автоматически следует за шаром
- ПКМ — свободный обзор (опционально)

### Общие команды
- **R** — рестарт уровня
- **N** — следующий уровень

## Игровая механика

### Материалы
- **Стекло** (синий) — низкая прочность, большой радиус разрушения
- **Дерево** (коричневый) — средняя прочность
- **Камень** (серый) — высокая прочность, малый радиус разрушения
- **Металл** (серебристый) — не разрушается в MVP

### Порталы
- Пара порталов создаёт туннель между двумя точками
- Сохраняют импульс и угол шара
- Визуально: голубые кольца с прозрачностью

### Жидкость
- Shallow-water симуляция (2D высотное поле)
- Толкает шар при контакте
- Выпускается при разрушении дамбы (стеклянных стенок)

### Финиш
- Зелёная коническая зона
- Уровень пройден при попадании шара

## Архитектура

### Структура проекта

```
/src
  core/          # Ядро: математика, физика, сетка, разрушение, порталы
  game/          # Игровая логика: уровни, геймплей, материалы
  render/        # Рендеринг: сцена, воксели, UI, дебаг
  app/           # Главное приложение
  main.ts        # Точка входа

/assets
  levels/        # JSON файлы уровней

/tests           # Unit и E2E тесты
```

### Ключевые модули

- **Grid3D** — 3D сетка вокселей с чанками
- **Ball** — физика шара (semi-implicit Euler)
- **SDF** — Signed Distance Field для коллизий
- **Portals** — телепортация с сохранением импульса
- **Fluid** — shallow-water симуляция
- **VoxelRenderer** — InstancedMesh для рендеринга вокселей

## Производительность

- Целевой FPS: **60** на ноутбуке 2019+ при 1080p
- Воксели: ≤ 100k видимых
- Разрушение: инкрементальные обновления по dirty-списку
- Физика: фиксированный шаг 120 Гц
- Рендер: vsync

## Уровни

1. **Dam Break** — разрушение стеклянной дамбы для выпуска воды
2. **Portal Bridge** — использование порталов для пересечения препятствий
3. **Multi-reservoir** — несколько резервуаров и порталов
